How rough will next week be?

A barometer for stocks. It forecasts how much a stock is likely to move over the next five trading days, turns that into a likely price range, and explains it in plain words. It reads the size of moves, never their direction.

This is a saved copy of the AAPL forecast from 2026-10-18. The live app needs a server for prices and notes; the README shows how to run it.

QLIKE is the standard score for volatility forecasts. It punishes calling a rough week calm more than the reverse. Full method and every number are in the README.

Prices from Twelve Data, headlines from Finnhub, charts by TradingView. Notes written by a language model on Groq from the numbers shown, with a check that drops any advice. Nothing here is investment advice. Source on GitHub.
